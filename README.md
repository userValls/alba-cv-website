# Alba Valls Carol - CV Website

## 1. User Profile
--------------------
The website is made for people who want to know more about me and my experience. The main users are companies, recruiters and people looking for someone to work with.

**User persona:**

- **Name:** Laura
- **Age:** 30
- **Job:** Recruiter
- **Goal:** Find information about my studies, skills and work experience.
- **Needs:** A clear and simple website where she can find information quickly.

The website helps Laura understand my profile and see if I could be a good candidate for a job.

## 2. Information Architecture
--------------------------------
My website is a single-page website. I divided the information into different sections to make it easy to use and understand.

At the top of the page, there is a navigation menu with links to the main sections. This helps users move directly to the information they want to see.

The first section is the introduction. It shows my name, a short description of myself and my photo. There are also buttons to contact me and download my CV.

The profile section gives more information about me, my studies and my professional goals. The experience section shows my previous jobs and activities, with the dates and a short description of each one.

The education section contains information about my university studies and previous education. After that, the skills section shows some of my personal skills. The languages section shows the languages I speak and their level.

Finally, the contact section includes my email, phone number and location. This makes it easy for companies to contact me.

I chose this order because I think users should first know who I am and then find more detailed information about my experience and education. All the information is on the same page, so users do not need to open different pages.

## 3. Visual Design
---------------------------
I designed the website using Figma before writing the HTML and CSS code. I wanted a simple and clean design that looks professional but is also personal.

I chose navy blue, orange, cream and beige as the main colours. Navy blue is used for the introduction and contact sections. It gives the website a serious and professional look. Orange is used for details, lines and buttons to make important elements stand out. Cream and beige are used for backgrounds because they make the page look softer and help the text stand out.

I use two fonts: Lato for the main text and Raleway for the headings. I chose these fonts because they are simple and easy to read. The main heading is large so my name is easy to see.

I also use cards for the experience and education sections. This helps separate the information and makes the page easier to read. The section titles have numbers and a small orange line to keep the same style throughout the website.

My photo is included in the introduction because I want the website to feel more personal. I also added buttons and links to help users navigate the page.

The website uses HTML and CSS without any external frameworks. I also added media queries in CSS to adapt the layout to smaller screens, such as mobile phones. My goal was to make the website simple, clear and easy to use.
